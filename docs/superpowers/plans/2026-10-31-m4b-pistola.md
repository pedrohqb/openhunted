# M4b — a pistola: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** o Jake atira com a pistola; as balas matam as minas e faíscam nas paredes; a
munição aparece no HUD.

**Architecture:** estados de tiro na máquina do Jake (`jake.rs`), que produz `Shot`s; a cena
transforma em entidades bala/cápsula (`behaviour/bullet.rs`, `casing.rs`) e resolve impactos.

**Tech Stack:** Rust 2024 (MSRV 1.85), SDL3 no viewer.

**Spec:** `docs/superpowers/specs/2026-10-31-m4b-pistola-design.md`

## Global Constraints

- GPL-3.0-or-later/SPDX; português; nada de dados do jogo no repo; `/home/claude/check.sh`
  verde antes de cada commit; constantes com endereço (dos docs `docs/re/`).

## Review Focus

1. ATIRAR seguro sem soltar: rajadas a cada 6 tiques, munição nunca negativa.
2. Atirar encostado na parede (boca dentro do sólido): nenhuma bala, nada preso.
3. Bala nascendo fora da fase (Jake na borda, mira para fora) → some sem panicar.
4. Mina morta por bala a < 42 px do Jake → a explosão fere o Jake (como no original).
5. Jake morto ou entrando na porta: ATIRAR não faz nada.

### Task 1: inventário e estados de tiro do Jake

**Files:** Modify `jake.rs`, `scene.rs` (inventário de `points`), `input.rs` (constantes já
existem: SHOOT 0x100).

**Interfaces (Produces):**
```rust
pub struct Inventory { pub slots: [(i32, i32); 30] }  // (tem, munição); índice = número da arma
impl Inventory { pub fn from_points(p: &[(i32, i32)]) -> Self; pub fn pistol_ammo(&self) -> i32; }
pub struct Shot { pub x: i32, pub y: i32, pub vx: i32, pub vy: i32 /* px/tique */, pub casing: bool }
pub enum Aim { Forward, Up, DiagUp, DiagDown }
impl Aim { pub fn from_input(bits: u32) -> Aim; pub fn label(self) -> u16 /* 23/56/54/55 */;
    pub fn muzzle(self, right: bool) -> (i32, i32); pub fn velocity(self, right: bool) -> (i32, i32); }
State::{ Fire { aim: Aim, t: u32 }, Recover, Ready(u32), Holster }
Jake { pub inventory: Inventory, pub shots: Vec<Shot>, ... }
Jake::aim_side(&self) -> bool
```
- Regras: ATIRAR (bit) em Idle/Run/Push/Land → `Fire{aim, t: 0}` (vx = 0); por tique em
  Fire: `t += 1`; se `1 ≤ t ≤ 3` e munição > 0 → gasta 1, `shots.push(Shot{...})` (1ª e 3ª
  com desvio perpendicular ±1 px/tique: 1ª `(−vy, vx)/|v|`, 3ª o oposto; `casing` só na 1ª);
  `t == 7 && ATIRAR` → `t = 0`, nova mira; `t > 12` → Recover; em Fire com ATIRAR solto
  e direção/pulo apertados após `t > 6` → Idle. Recover: anim_done → Ready(0); Ready(n): n
  ≥ 10 → Holster; direção/pulo em Ready/Holster → Idle; Holster: anim_done → Idle. ATIRAR
  em Ready/Holster/Recover → Fire. Lado: ESQ/DIR mudam `facing_right` também em Fire.
  Sem munição ao apertar: `Event::Sound(3090)` via `pub no_ammo: bool` consumido pela cena.
  `label_changed` ao reiniciar a rajada (mesmo rótulo): forçar `label_changed = true`.
- Jake morto/EnteringExit/Shocked etc.: ATIRAR ignorado (já são estados passivos).
- Scene::build: `inventory = Inventory::from_points(&o.points)`; par 1 = (1, 20).

### Task 2: bala, cápsula e impactos

**Files:** Create `behaviour/bullet.rs`, `behaviour/casing.rs`; Modify `entity.rs`
(`Behaviour::Bullet(BulletState)`, `Casing(CasingState)`, consts `BULLET = 19`, `CASING =
22`), `scene.rs`, `behaviour/mod.rs` (`Out.impacts: Vec<(i32, i32, i32 layer)>`).

- `scene.rs`: ao fim do tique do Jake, para cada `Shot`: `bullet_entity(shot)` (OBU.ANM,
  rótulo/espelho pela direção: |vx| > 2|vy| → 1, |vy| > 2|vx| → 3, senão 2; mirror
  horizontal se vx < 0, vertical se vy > 0 — Ruling: a arte aponta para a direita/cima;
  escala 10/largura ou altura do quadro conforme a maior dimensão; caixa = BRD `OBUxx.BRD`
  correspondente; flags 0x2019; layer do Jake) e, com `casing`, `casing_entity`.
- `bullet::tick`: `step` sem gravidade contra `ctx.cells`; `hit_wall || hit_ceiling ||`
  (parou) → impacto; fora da fase → `alive = false` sem impacto. Depois, na cena: para cada
  bala viva, entidades vivas sólidas (`flags & 0x80003 == 0x80001`, sem 0x20, mesma camada,
  não bala/cápsula) cuja caixa cruza a da bala → vítima: mina → `health = 0` e
  `pending 2`; qualquer → impacto na posição da bala. Impacto → `out.impacts.push(center)`
  → `explosion_entity` com rótulo 15 e raio 5 (sem área: `Blast.damage = 0` → não aplicar
  dano) e `Event::Sound(3046)`.
- `casing::tick`: `step` com gravidade contra `ctx.cells`; `hit` → evento 3020/3021 (uma
  vez); `|vx| < 8 && |vy| < 8` por 2 tiques seguidos ou fora da fase → `alive = false`.
- Som 3040 ao entrar num estado de tiro (evento emitido pela cena via `jake.label_changed`
  e `label ∈ {23,54,55,56}`).
- [ ] Testes sintéticos: bala a 20 px/tique; parede → faísca (entidade 86 com rótulo 15) e
  bala some; bala mata mina; cápsula cai e some; bala fora da fase some. Real: na T_J_001,
