# M9 — casca completa: plano de implementação

**Goal:** opções gravadas, jogo salvo e lista de heróis, as telas `.ITF` restantes, música
dos menus e das faixas, filmes pelo `ffmpeg`, `S_CAR` e créditos.

**Spec:** `docs/superpowers/specs/2026-11-06-m9-casca-design.md`

## Global Constraints

- GPL-3.0-or-later/SPDX; português; nada de dados do jogo; `/home/claude/check.sh` verde
  antes de cada commit; constantes com endereço.
- M8 e a correção da M7a correm em paralelo: motor (`scene.rs`, comportamentos) intocado;
  `viewer.rs` intocado; em `shell.rs` (app), acréscimos; testes antigos continuam valendo
  (a gravação só liga com `App::with_storage`).

## Review Focus

1. Arquivo salvo nunca carrega ponteiro: `0x7a0`/`0x7a4` zero na escrita; leitura ignora.
2. Nada é gravado em `~` pelos testes (pastas temporárias).
3. Sem `ffmpeg`, sem pasta de música ou sem áudio: tudo segue sem panicar.
4. Laço do mixer sem estalo (posição volta ao início) e sem alocar no callback.
5. Entrada de texto só durante o `SHIGH`; espaço digita, não clica.

### Task 1: formato `.hhg` e `hunter.fam` (`openhunted-formats/src/save.rs`)

`SaveGame { name, list_len, solo_count, current, last_loaded, total, hero_id, pieces,
path, level, records: Vec<i32> }` com `parse`/`to_bytes` (1 960 bytes, assinatura);
`HeroList { counter, heroes: Vec<Hero> }` com `parse`, `to_bytes(chave)`, `qualifies`,
`record(nome, pontos, id) -> id`. Testes: ida e volta, deslocamentos, zeros, XOR, 14.

### Task 2: configuração (`openhunted-engine/src/shell/config.rs`)

`Config { difficulty, music_volume, sfx_volume, brightness, no_music_start, music_dir }`,
`parse(&str)`, `write(&self, original) -> String` (mantém o resto), padrões e faixas;
`movie_variant(brightness)`; `palette_name(brightness)`.

### Task 3: `Screen` — opções e quadro manual

`Screen::make_option(id)` (clique ao apertar; quadro 2/1/0 por marcado/realce),
`set_marked`, `set_label_frame`, `play_once` (para no último quadro), `hit`.

### Task 4: páginas (`shell/pages.rs` …)

Trait `Page` (`handle(Input, &mut sons) -> Option<Reply>`, `draw`, `screen`, `text`,
`backspace`); `Options`, `LevelSelect`, `Heroes`, `NameEntry`, `Car`, `Info` (SMULT,
SINPU, SKEYB, SABOUT). Testes sintéticos + todas as `.ITF` reais montam e desenham.

### Task 5: mixer com laço, `stop`, mestre; `MusicPlayer` (app `audio.rs`, `music.rs`)

### Task 6: filmes (`video.rs`): `Decoder`, `Movie`, `FfmpegDecoder`; sequência
(preto, voz, filme, créditos).

### Task 7: `App`: armazenamento, páginas, salvamento, peças, música, filmes; `main.rs`
(texto, duas saídas, abertura); `shots`.
