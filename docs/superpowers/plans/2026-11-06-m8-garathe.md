## Global Constraints

- GPL-3.0-or-later/SPDX; português; nada de dados do jogo; `/home/claude/check.sh` verde
  antes de cada commit; constantes com endereço.

- Os 380 testes existentes continuam verdes a cada commit (o perfil do Jake não muda nada).

## Review Focus

1. Nenhum número do Jake muda: as constantes saem do perfil com os mesmos valores.
2. Rótulos do Garathe existem no `MINOTAUR.ANM` (teste com os dados reais).
3. Munição nunca negativa; a faca/estrela cravada recolhida pelo personagem certo.
4. O chicote não se multiplica sem fim (4ª geração, some na parede).
5. Fuzz: o Garathe nunca dentro de sólidos.
